# TeamTasks

TeamTasks е уеб приложение за организиране на проекти и задачи в екип. Потребителите могат да създават проекти, да добавят задачи към тях и да прикачват файлове. Приложението включва администраторски панел за управление на потребителите.

## Публикувана версия

- **Уеб приложение:** https://team-tasks-ut3r.netlify.app/
- **GitHub хранилище:** https://github.com/tedislawyer/team-tasks

## Използвани технологии

- HTML5, CSS3 и JavaScript
- Bootstrap
- Vite и npm
- Supabase — база данни, удостоверяване на потребители и файлово хранилище
- Netlify — публикуване на приложението
- Git и GitHub — контрол на версиите и съхранение на изходния код

## Основни функционалности

- Регистрация и вход на потребители
- Създаване и преглед на проекти
- Добавяне, преглед и редактиране на задачи
- Избор на статус на задачата
- Качване, изтегляне и изтриване на прикачени файлове
- Потребителски профили и роли
- Администраторски панел
- Ограничаване на достъпа до данните чрез политики за сигурност в Supabase

## Структура на проекта

- `index.html` — начална страница
- `login.html` и `register.html` — вход и регистрация
- `projects.html` — списък с проекти
- `project.html` — подробности за проект и неговите задачи
- `task.html` — създаване и редактиране на задача
- `admin.html` — администраторски панел
- `src/pages/` — JavaScript логика за отделните страници
- `src/components/` — споделени интерфейсни компоненти
- `src/services/` — връзка със Supabase
- `src/styles/` — стилове на приложението
- `supabase/migrations/` — SQL миграции за базата данни

## Стартиране локално

Необходими са инсталирани Node.js и npm.

1. Клонирайте хранилището:

   ```bash
   git clone https://github.com/tedislawyer/team-tasks.git
   cd team-tasks
2. Инсталирайте зависимостите:
bash


npm install
3. Създайте .env файл в основната папка на проекта и добавете настройките от Supabase:
VITE_SUPABASE_URL=адресът-на-supabase-проекта
VITE_SUPABASE_PUBLISHABLE_KEY=публичният-supabase-ключ
4. Стартирайте приложението за разработка:
bash
npm run dev
5. Създайте production build:
npm run build
База данни и сигурност
Приложението използва Supabase за удостоверяване, релационна база данни и файлово хранилище. Миграциите са в supabase/migrations/. Row Level Security (RLS) политиките ограничават достъпа до данните според потребителските права.

Тестване на публикуваната версия
Отворете TeamTasks в Netlify и проверете регистрацията, входа, създаването на проект и задачите, прикачените файлове и администраторския панел.

Известно ограничение: В момента бутонът за създаване на нова задача не предава правилно избрания проект. Тази функционалност трябва да бъде поправена и проверена преди окончателното предаване.
